W.I.T.N.E.S.S. - Admin Dashboard

Welcome to the hidden administrative section of the W.I.T.N.E.S.S. system.

  • System Check
    Checks whether all required technologies are installed and up to date, including Python libraries, Ollama, Piper TTS, Faster-Whisper, and ffmpeg.
  • Voice Demonstrations
    Lets you audition all installed Piper TTS voices using custom text before assigning them to a persona.
  • Custom Dictionary
    This tool allows you to add custom words to the spell checker, such as persona names (Priya, Mereana), NZ place names, and technical terms.
